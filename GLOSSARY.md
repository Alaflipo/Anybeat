# Anybeat

Anybeat uses a looping timeline to arrange and play music.

## Language

**Note block**  
The timeline representation of a single pitched note or drum hit with a start time and duration.

**Playhead**

The timeline marker for the current position in the loop.

**Seek**

Moves the playhead to a chosen position for the next playback.

**Pause**

Halts playback and holds the playhead at its current position so playback can resume there.

**Reset**

Ends the current playback session and returns the playhead to the beginning, ready for the next Play.
